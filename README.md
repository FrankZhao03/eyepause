# EyePause 0.2.0

A lightweight macOS app for screen breaks and hydration reminders.

原生 macOS 菜单栏眼睛休息工具。图标为系统的 `binoculars.fill`（望远镜），不使用眼睛或太阳表情，不显示 Dock 图标。数据只保存在本机，没有账号、订阅、网络和分析服务。

## 打开与退出

双击 `outputs/EyePause.app` 打开。常驻图标在菜单栏，点击后显示倒计时、统计和操作。“设置…”打开独立窗口，“退出 EyePause”完全退出程序。

退出后，重新双击同一个应用即可打开。如果放入“应用程序”文件夹，也可以用 Spotlight 搜索 EyePause 打开。不要打开 `EyePause-0.1-backup.app`，那是修复前的备份。

建议先将新版放在固定位置，再在设置中打开登录启动。系统可能要求在“系统设置 → 通用 → 登录项”中批准。登录启动尚未经过真实注销/登录或重启验证。

这是本地临时签名的应用，没有开发者公证。若系统阻止打开，应检查系统的“隐私与安全性”提示，不需要关闭系统安全功能。喝水使用应用自身的窗口，不需要系统通知权限。

## 明确的计时规则

### 眼睛休息

默认累计 20 分钟使用，然后休息 20 秒：

- 最近 30 秒有输入：累计使用时间。
- 无输入 30 秒到 2 分钟：冻结眼睛倒计时。
- 无输入至少 2 分钟：自然休息，重新开始下一轮。
- 已知会议、播放器、演示应用在前台时：视为被动看屏幕。
- 浏览器在前台且系统存在防熄屏状态时：也视为被动看屏幕。这只是启发式判断，不能准确判断视频或眼睛是否看着屏幕。
- 睡眠、锁屏、会话不活跃、屏幕睡眠：停止计时。多个暂停原因分别记录，唤醒不会误清除仍存在的锁屏状态。
- 锁屏或睡眠期间中断的弹窗会关闭，不算“完成休息”；离开时间达到自然休息阈值后重置使用周期。

只有计时核心拥有休息截止时间，使用单调时钟。弹窗和菜单栏读取同一个状态，不各自计时。休息结束自动关闭且只记一次完成；重复点击不会重启正在进行的倒数。“跳过”不计入完成次数。

手动暂停会关闭正在进行的休息和喝水弹窗。点击“现在休息”会恢复计时并开始休息。

### 喝水

默认每 60 分钟电脑醒着、未锁屏、未手动暂停的运行时间提醒。阅读没有输入也计时，眼睛休息也计时；应用完全退出期间不累计。

到点打开简单弹窗，不倒数、不强制关闭：

- “我喝了”：关闭并从头计算下一个提醒。
- “10 分钟后提醒”或关闭窗口：延后 10 分钟。
- 眼睛休息期间到点：等休息结束再弹出。
- 锁屏、睡眠或手动暂停：不弹出；恢复后重新处理到点的提醒。
- 关闭喝水提醒开关：关闭已有弹窗并停止该计时。

### 菜单栏与统计

仅图标模式始终不占用文字宽度；自适应模式平时仅图标，距离休息不超过两分钟时显示剩余时间；始终显示模式在使用期间显示倒数。休息时自适应和始终显示模式都显示休息倒数。

今日屏幕时间和最长使用段来自上述检测规则，是估算值，不等同于 macOS Screen Time。每日统计在跨日时只重置一次；提醒周期独立于日统计。进度每 30 秒保存一次，正常退出和重要操作立即保存；强制终止可能丢失最多约 30 秒进度。手动暂停状态和喝水进度会保留到下次打开。

## 构建与验证

```sh
bash scripts/build-app.sh
bash scripts/test-engine.sh
bash scripts/test-integration.sh
```

界面测试需要可访问 Window Server 的 macOS 桌面环境，不能在禁止访问窗口服务的沙盒内运行。测试使用随机命名的独立偏好，不读取或清除真实统计。界面测试会临时显示设置、喝水窗口及一轮真实的 20 秒休息。

打包应用的隔离启动检查：

```sh
./outputs/EyePause.app/Contents/MacOS/EyePause --audit-startup
```

该模式使用独立测试偏好，约 5 秒后退出。不会更改真实统计。旧的 `--preview-break` 模式已移除，避免预览写入真实进度。

真机登录启动、锁屏、睡眠、不同浏览器的视频检测和多显示器仍需验证。
